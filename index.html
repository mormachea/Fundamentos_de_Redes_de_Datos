1. Introducción a las Redes de Datos

Una red de computadoras es un conjunto de equipos autónomos e interconectados mediante una determinada tecnología (cables de cobre, fibra óptica, microondas, satélites) capaces de intercambiar información y compartir recursos.

Conceptos Clave:
  • Cliente-Servidor: Arquitectura donde los datos residen en equipos potentes (servidores) y son consumidos por terminales del usuario (clientes).
  • Peer-to-Peer (P2P): Arquitectura donde todos los nodos actúan de forma simétrica como clientes y servidores simultáneamente.
  • Conmutación de Paquetes: Técnica mediante la cual los datos se dividen en fragmentos con encabezados (paquetes) que viajan de forma independiente por la red.

2. Hardware y Software de Red

El funcionamiento de una red se compone de la interacción precisa entre dispositivos físicos (Hardware) y los protocolos y lógica de conmutación (Software).

Switch (Conmutador)

Dispositivo de Capa 2 (Enlace de Datos). Interconecta equipos dentro de una misma red LAN utilizando direcciones MAC. Reenvía tramas de manera conmutada.

Router (Enrutador)

Dispositivo de Capa 3 (Red). Interconecta redes lógicas distintas y toma decisiones de ruta para enviar los paquetes hacia su destino remoto (Direccionamiento IP).

Access Point (AP)

Dispositivo que permite la conexión inalámbrica de estaciones cliente a la red alámbrica mediante estándares como IEEE 802.11 (WiFi).

5. Direccionamiento IP v4 y VLANs

Una dirección IPv4 es un identificador lógico de 32 bits codificado en 4 octetos separados por puntos (ejemplo: 192.168.1.10). Se compone de una parte de Red y una parte de Host, definida por la máscara de subred.

Clases de Direcciones IPv4 Tradicionales:
  • Clase A: 1.0.0.0 a 127.255.255.255 (Máscara /8)
  • Clase B: 128.0.0.0 a 191.255.255.255 (Máscara /16)
  • Clase C: 192.0.0.0 a 223.255.255.255 (Máscara /24)
¿Qué es una VLAN (Virtual LAN)?

Una VLAN permite segmentar lógicamente una red de área local física en múltiples dominios de difusión independientes dentro del mismo switch, mejorando la seguridad y reduciendo el tráfico de broadcast de la red.

8. Guía Completa: De GitHub a APK Android (Cordova / Capacitor)

A continuación se detallan los pasos exactos para subir este proyecto a un repositorio de GitHub y compilarlo como un paquete instalable de Android (.APK).

Paso 1: Subir el proyecto a GitHub
# Inicializar repositorio Git local
git init

# Agregar el archivo index.html
git add index.html

# Crear el primer commit
git commit -m "Inicializar App Fundamentos de Redes"

# Vincular con tu repositorio remoto de GitHub y subir
git remote add origin https://github.com/TU_USUARIO/fundamentos-redes-app.git
git branch -M main
git push -u origin main
Paso 2: Generar la APK nativa con Apache Cordova

Requisitos previos instalados en tu computadora: Node.js, Java JDK y Android Studio / SDK.

# 1. Iniciar proyecto de Cordova
npm install -g cordova
cordova create RedesApp com.fundamentos.redes RedesApp
cd RedesApp

# 2. Copiar este archivo index.html dentro de la carpeta /www/
cp ../index.html www/index.html

# 3. Agregar la plataforma Android
cordova platform add android

# 4. Compilar para obtener la APK en modo Debug
cordova build android

# La APK generada se ubicará en:
# /platforms/android/app/build/outputs/apk/debug/app-debug.apk
Tip Alternativo (Capacitor): También puedes usar @capacitor/core y @capacitor/cli con la orden npx cap add android y compilar la APK directamente desde la interfaz gráfica de Android Studio.

1. Introducción a las Redes de Datos

Una red de computadoras es un conjunto de equipos autónomos interconectados mediante una determinada tecnología capaces de intercambiar información y compartir recursos.

  • Cliente-Servidor: Arquitectura donde los clientes solicitan recursos centralizados a servidores.
  • Conmutación de Paquetes: División de datos en fragmentos independientes (paquetes) con encabezados IP.

2. Hardware y Software de Red

Switch (Capa 2)

Conmuta tramas utilizando direcciones físicas MAC dentro de la misma LAN.

Router (Capa 3)

Enruta paquetes entre redes lógicas distintas utilizando direcciones IP.

Access Point

Proporciona conectividad inalámbrica según estándares IEEE 802.11 (WiFi).

5. Direccionamiento IPv4 y VLANs

Una dirección IPv4 consta de 32 bits codificados en cuatro octetos (ej. 192.168.1.1). Las VLANs (Virtual LANs) permiten agrupar nodos de manera lógica independientemente de su ubicación física.

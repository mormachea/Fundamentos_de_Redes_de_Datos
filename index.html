1. Historia y Evolución a Redes Convergentes

Evolución de la Computación

Desde los primeros mainframes aislados hasta el procesamiento distribuido, la necesidad de compartir recursos computacionales impulsó el nacimiento de las redes de datos.

Aislamiento

Mainframes y tarjetas

Convergencia

Voz, Video y Datos IP
Redes Convergentes

Una Red Convergente integra múltiples servicios (telefonía VoIP, streaming de video y tráfico de datos web) sobre una única infraestructura IP estandarizada.

2. Conceptos Básicos de Redes

Una red de datos es la infraestructura que permite interconectar nodos autónomos para compartir archivos, aplicaciones y servicios.

3. Hardware y Software de Red
